# Aegis project context

Aegis (Adaptive Enterprise API Defense Platform) is a controlled, enterprise-inspired API security platform built around a synthetic FinTech application. Its canonical repository structure is retained in this repository.

Security decisions must be policy- and evidence-driven: deterministic authorization and security controls come before probabilistic intelligence. Aegis must not implement a universal weighted risk score that directly decides whether to block.

Phase 1 (development environment and repository foundation) is complete. Phase 2 (the synthetic FinTech application) is implemented as three independent Spring Boot services. Attack activity is limited to project-owned systems, synthetic data, and controlled scenarios.
